# Tests

microT-FS のテストは「1 テストケース = 1 実機 IDE プロジェクト」にはしません。再利用可能なテストケースと、ボードおよび互換性のあるビルド構成ごとのテストランナープロジェクトを分離します。

## Structure

- `common/framework/`: テスト登録、実行、結果報告など、ランナー非依存の小さなテスト基盤
- `common/cases/`: microT-FS の公開 API と共通契約を検証するテストケース
- `host/`: ホスト向けランナーおよび高速な開発時テスト
- `targets/ek_ra8p1/basic/`: EK-RA8P1 の互換ビルド構成をまとめる基本ランナー
- `targets/stm32n6570_dk/basic/`: STM32N6570-DK の互換ビルド構成をまとめる基本ランナー

各ボード別ランナーは、SDK 初期化、ストレージ接続、ランナー用設定、ビルド定義だけを担当し、`common/framework/` と `common/cases/` を同じビルドへ組み込みます。ボード固有の確認が必要な場合も、ケース本体とランナーの責務を分け、互換構成間でプロジェクトを不必要に複製しない方針です。

初期構成には実装コードや IDE プロジェクトをまだ含みません。`tron2026_work` の成果は参照できますが、既存プロジェクトをそのままコピーせず、上記の責務に沿って再構築します。
